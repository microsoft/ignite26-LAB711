# [Microsoft Ignite 2026](https://ignite.microsoft.com)

## 🔥LAB711: Zero Trust Lab: Securing Identities and Devices with Intune & Entra
### Session description

Apply Zero Trust principles to prepare a secure foundation for AI across identities, devices, agents, and data. Investigate sample assessment findings, create a scoped report-only Conditional Access policy and an unassigned Windows update ring, and record your priorities and next steps in the Zero Trust Workshop.

The [participant guide](instructions/instructions.md), titled **Build an AI-Ready Secure Foundation with Zero Trust**, includes guided and self-paced instructions.

### 🚀 Getting started

#### In a guided session

If you're following along during a live session:

1. Launch the supplied lab VM and use the credentials provided by the lab platform.
2. Open the [participant guide](instructions/instructions.md) and complete **Before you begin**.
3. Follow the instructor through the assessment, identity, device, agent, and data sections. Save your Workshop notes and complete the safe-exit checks.

#### On your own

If you're learning at your own pace:

1. Use a dedicated test tenant and lab device, never a production tenant. You need permissions and licensing for Microsoft Entra Conditional Access and Microsoft Intune.
2. Open the [participant guide](instructions/instructions.md). Use the prepared assessment and written examples; instructor demonstrations are not required to follow the steps.
3. Keep the pilot group empty, the Conditional Access policy in **Report-only**, and the update ring unassigned. Review your Workshop report and sign out when finished.

### 🎯 Learning outcomes

By the end of this session, you will be able to:

- Investigate identity and device assessment findings, distinguish configuration evidence from verified protection, and prioritize a response.
- Configure a scoped report-only phishing-resistant authentication policy and an unassigned Windows update ring, with a plan to verify rollout results.
- Review agent ownership and data-protection considerations, and record an actionable Zero Trust plan in the Workshop Progress Report.

### 💻 Technologies used

- Microsoft Zero Trust Assessment and Zero Trust Workshop
- Microsoft Entra ID and Conditional Access
- Microsoft Intune and Windows update rings
- Microsoft Agent 365
- Microsoft Purview Data Security Posture Management and sensitivity labels
- Microsoft 365 Copilot
