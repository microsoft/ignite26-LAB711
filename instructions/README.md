# Attendee instructions

Start with the [LAB711 participant guide](instructions.md) for both the guided session and self-paced learning.

Use the supplied lab environment or a dedicated test tenant, never production. The hands-on exercises create an empty pilot group, a report-only Conditional Access policy, and an unassigned Windows update ring. Agent and data-protection sections are reference overviews, not participant configuration exercises.

The guide remains a draft. Screenshot requests are retained for review, and portal access, lab provisioning, and the complete attendee flow still need validation. The included demo images do not establish that controls are enforced in your tenant.
